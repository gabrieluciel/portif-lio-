Lógica de Programação

É uma organização de passos e regras que mostram para o computador como resolver um problema de forma correta. Aqui está um algoritmo em pseudocódigo (portugol), que armazena dados por meio de vetores e utiliza variáveis, constantes, estruturas de repetição, e estruturas condicionais para procurar um CPF e retornar a idade, nome e departamento.

Banco de Dados

Sistemas Embarcados e Internet das Coisas (IoT)

Sistemas Embarcados são computadores dedicados dentro de um aparelho para uma função própria, IoT conecta esses aparelhos à internet. Nessa atividade utilizei um Arduino em linguagem C++.
